# IBS Next-generation front end

This is an isolated React + TypeScript + Vite front-end prototype. It is intentionally separate from the production application and uses demonstration data only. It does not connect to Supabase or write user records.

## Local development

From the repository root:

```sh
npm install
npm run build:next
npm start
```

Open `http://localhost:8787/next-preview/index.html`.

The prototype validates the design direction and responsive layout. It is not feature-complete and is not yet connected to the existing study records, Bible data, authentication, AI Mentor or Kerygma services.
